# PA2 data files

This directory contains the files supplied for DAL-585 PA2. They are included in the runnable ZIP for convenience. Before committing or publishing these files, confirm the course's data/assignment redistribution policy. The repository `.gitignore` excludes `*.tags`, `*.sents`, and `*.out` by default. If a private Git repository is permitted to carry the files, use a deliberate, reviewed exception rather than blindly forcing course data into a public repository.
